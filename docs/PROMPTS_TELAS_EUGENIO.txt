120 imágenes de prueba · 10 por familia · una imagen por prompt

Copia solo el párrafo bajo PROMPT. Guarda el resultado con el ID de cada bloque.
COMPROBAR es la expectativa para las pruebas, después de verificar la imagen a mano.
Las dos últimas imágenes de cada familia se reservan para la comprobación final.
