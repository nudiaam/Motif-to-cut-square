# Lalikul Cut Prep 0.13.3

El 16 de noviembre de 2026 se cambia el nombre de la versión local
`0.13.0-rc3` a **0.13.3**, a petición del usuario.

Solo cambia la identificación de versión de la aplicación. Se conservan el
detector, la colocación, las dimensiones y la exportación de rc3. Su revisión
interna de detector permanece igual para mantener la trazabilidad.

Las 330 pruebas y la comparación de 62 imágenes corresponden al código
comprobado como rc3; no se presentan como una nueva ejecución de detección.
Los resultados, las limitaciones y el antes y después se conservan en
[el informe original](RELEASE_0_13_0_RC3.md).

El paquete local se encuentra en
`output/lalikul-0.13.3/lalikul-0.13.3.zip`. No se ha publicado un tag ni se ha
realizado una instalación externa.
